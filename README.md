# bot_for_help
## Телеграмм-бот для технической поддержки
## Инструменты для реализации:
> библотеки:
> PyTelegramBotAPI
> sqllite3
> Python

## Проект состоит из:
> config.py
> main.py
> logic.py



## Что умеет этот бот?
1. Помогать пользователям с техническими вопросами и проблемами.
2. Может считывать текст. 
3. Может дать пользователю возможность создавать свои ответы.

## Запуск и работа с ботом

> Установите зависимости 'pip install pyTelegramBotAPI, sqlite3, datetime, InlineKeyboardMarkup, InlineKeyboardButton'
> Запустите logic а потом main
